# 六轴从站改动清单

对照基线：`main` @ `746977b`

## 1. 电机层

- 新增 RobStride 私有协议驱动（RS02 / RS03），只保留 **MIT 运控模式**（Type 1：P / V / Tff / Kp / Kd）。
- `motor_config.c` 定义六轴：CAN0 = Axis 1~3，CAN1 = Axis 4~6；每个轴的启停开关是 `.enabled`。
- 启动探测：用 Type 17 读 `0x7005`，校验 CAN 总线、motor ID、host ID；窗口内无有效应答则锁存 `NO_FEEDBACK`，该轴不进入使能流程。
- 使能顺序：写 `run_mode=operation` → 50 ms → 使能 → 50 ms → 运动帧。
- 安全：命令超时 100 ms、反馈超时 250 ms、停止帧有界重试（最多 5 次）、CAN bus-off 锁存。
- 故障锁存只能由重新初始化或显式复位清除；主站重连、OP 重建、普通运动命令都不会清除。

## 2. EtherCAT / PDO

- PDO 契约不变：RxPDO 320 B（16 轴 × 5 × REAL32），TxPDO 252 B（60 B IMU + 16 轴 × 3 × REAL32）。
- `gateway_app.c/.h` 与 `main` 一致，未改动。
- ENCOS / RS06 旧驱动源文件保留在 `protocols/encos`、`protocols/rs06`，但不再加入 CMake 构建。

## 3. 明确不实现

- PP / 速度 / 电流 / CSP 四种模式：EtherCAT PDO 没有对应接口，不实现。
- 修改电机 ID、设置机械零位、保存参数、通信协议切换：都由 PC 调试工具完成，网关不实现。
- 参数读写（Type 17/18 通用接口）：网关不提供。

## 4. 本次删除

- 五模式状态机与相关诊断接口（`service_mode_switches`、`build_mode_frames`、`service_mode_control`、`motor_manager_get_mode_diagnostic` 等）。
- 主机测试文件与测试脚本（`tests/motor_*`、`tests/robstride_proto_test.c`、`scripts/run_host_tests.ps1`）。
- 过程文档 `docs/44-motor-config-ball-slave-plan.md`；只保留本清单。
