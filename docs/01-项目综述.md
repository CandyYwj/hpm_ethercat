# 项目综述 (2026-07 更新)

## 1. 项目目标

本工程将 HPM6E80 full-port 板作为 **16 轴 MIT 型电机 EtherCAT 从站**：

- 通过 EtherCAT 接收 RDK X5 主站的 16 轴 MIT 指令 (pos+vel+trq+kp+kd)
- HPM6E80 固件解析 PDO → 未来通过 CAN FD 发送到电机驱动器
- 电机反馈通过 CAN 接收 → 打包到 PDO 返回主站

**历史:** 项目最初是“EtherCAT↔TSN 透传网关”。该转换代码现已删除，TSW
仅作为与 EtherCAT 独立的三端口硬件交换机。

## 2. 系统拓扑

```text
RDK X5 (EtherCAT Master)
  │
  │  EtherCAT 周期帧 (1ms)
  │  RxPDO 320B: [Motor0 cmd][Motor1 cmd]...[Motor15 cmd]
  │  TxPDO 192B: [Motor0 fb ][Motor1 fb ]...[Motor15 fb ]
  ▼
HPM6E80 (EtherCAT Slave)
  │
  │  固件: gateway_app.c + motor_manager.c
  │    APPL_OutputMapping → 解析 16轴命令
  │    APPL_InputMapping  → 打包 16轴反馈
  │
  ▼
CAN0 → 3 × ENCOS + 1 × RS06 MIT

TSN Port1 <-> TSW hardware <-> TSN Port2/Port3
```

## 4. 当前 PDO 模型

| 参数 | 值 |
|------|-----|
| 轴数 | 16 |
| 每轴命令 | 5 × REAL32 = 20 bytes (pos, vel, trq, kp, kd) |
| 每轴反馈 | 3 × REAL32 = 12 bytes (pos, vel, trq) |
| RxPDO (SM2) | 320 bytes = 0x140 |
| TxPDO (SM3) | 252 bytes：60-byte IMU + 192-byte 电机反馈 |
| 命令对象索引 | 0x7010-0x7F14 (每轴偏移 0x100) |
| 反馈对象索引 | 0x6000-0x6F02 (每轴偏移 0x100) |
| RxPDO mapping | 0x1600-0x160F (16 个) |
| TxPDO mapping | 0x1A00-0x1A0F (16 个) |

## 5. 已验证状态

- 16轴 PDO 回调正确触发 (APPL_OutputMapping / APPL_InputMapping)
- EtherCAT 从站可进入 OP
- 串口日志: `PDO: 252 bytes in, 320 bytes out`
- SSC 状态可监控 (bEscIntEnabled, bDcSyncActive, nAlStatus 等)
- 测试反馈值 (enable_test_feedback) 可被主站读到
